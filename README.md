# LLM Red-Team & Jailbreak Vulnerability Tester

A security testing platform for evaluating the robustness and safety
of large language models against authorized adversarial probes.

## Features

- Jailbreak testing
- Prompt-injection testing
- System-prompt-leakage testing
- PASS/FAIL/UNCERTAIN classification
- Severity-based risk scoring
- JSON and CSV report generation
- Interactive Streamlit dashboard
- Ollama integration for local testing
